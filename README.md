# JCOUP 학생 수업 종합 포털 v1.5.1

## 이번 버전
- 수행평가 실제 응시 화면에 들어가면 상단 포털 메뉴(수업 진도·수업 자료실·공지·수행평가)를 숨기는 **수행평가 집중 모드** 적용
- 평가 안내문에 입력한 줄바꿈·개조식 형식을 학생 화면에서 그대로 보존
- 관리자 테스트 새 창에서는 기존처럼 선택 학생 정보와 응시코드를 자동 채움
- 실제 학생 접속에서는 응시코드가 자동 입력되지 않으며 학생이 직접 입력
- v1.5.0의 공지 메뉴·첨부파일, 기존 자동 저장·최종 제출 기능 유지

학생 저장소 `Jcoupe-class-portal`을 이 폴더 내용으로 전체 교체 후 Push합니다.
관리자 코드는 변경하지 않습니다.
