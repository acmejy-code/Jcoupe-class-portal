# JCOUP 학생 포털 v1.6.3 — 학사일정·수업진도 달력

기준: v1.6.2 대기실 재입장/기기 인계 기능을 모두 유지합니다.

## v1.6.3 추가 개선
- 수업 진도 화면에 관리자 달력과 유사한 월간 달력 추가
- 선택한 반의 정규 수업 예정 시간과 실제 공개 수업 기록을 한 달 단위로 표시
- 학교 학사일정을 날짜별로 함께 표시
- 휴일/수업 없음 날짜를 별도 배경으로 표시
- 이전 수업의 ‘다음 수업 시작점’을 다음 실제 예정 수업 칸에 미리 표시
- 이전 달 / 다음 달 / 오늘 이동 제공
- 모바일에서는 달력을 가로 스크롤하여 확인 가능

## 주의
관리자 v2.6.4에서 **학생 포털 발행**을 실행해야 달력용 학사일정과 전체 진도 데이터가 최신 상태로 표시됩니다.
