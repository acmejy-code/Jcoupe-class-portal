# JCOUP 학생 포털 v1.7.0 — 실전 수행평가 안정화

현재 GitHub 게시본 v1.6.8을 기준으로 수정한 전체 교체본입니다.

## 수행평가 저장 정책
- 답안 입력 즉시 브라우저 localStorage에 보관
- 서버 답안 자동저장은 남은 시험시간에 따라 단계적으로 조정
  - 20분 초과 남음: 10분 간격
  - 20~10분 남음: 2분 간격
  - 10~5분 남음: 1분 간격
  - 5~2분 남음: 30초 간격
  - 2~1분 남음: 15초 간격
  - 마지막 1분: 10초 간격
- 최종 제출 또는 시험시간 종료 시 즉시 서버 저장 및 제출 재시도
- 재연결 시 미저장 답안은 즉시 서버 동기화

## 접속·감독 정책
- heartbeat: 60초 주기. 최근 30초 내 답안 저장이 있었다면 중복 heartbeat 생략
- window blur 단독 감지 제거
- document.hidden이 3초 이상 지속된 경우만 화면 이탈 참고 기록
- 텍스트 선택·길게 누르기·컨텍스트 메뉴는 기록하지 않음
- 실제 답안 입력칸의 copy/paste 이벤트만 참고 기록
- 감독 이벤트는 즉시 별도 write하지 않고 다음 답안 저장/heartbeat에 묶어서 전송

## 기타
- 학생 화면 상단에 v1.7.0 표시
- 반별 수행평가 분리, localStorage 복구, 최종 제출 재시도 기능 유지
