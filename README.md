# JCOUP 학생 포털 v1.6.7 — 강제확정 후 최종답안 복구보존

## 누적 기준
v1.6.6의 입장 재시도, 연속입력 서버동기화, 종료 30초 전 긴급저장, revision 기반 마지막 수정 보존을 모두 포함합니다.

## v1.6.7 핵심 수정
- 관리자 강제확정(TIME_EXPIRED/TEACHER_CLOSE) 수신 시 로컬 최종답안을 즉시 삭제하지 않습니다.
- 서버 제출본과 기기 로컬백업이 다르면 복구 후보로 판정하고 세션 문서에 복구 스냅샷 업로드를 시도합니다.
- 네트워크가 나중에 복구되거나 페이지를 다시 열어도 남은 로컬백업을 재탐색하여 복구 스냅샷을 다시 전송합니다.
- 정상 수동 제출/학생 자체 자동제출은 제출 성공 후 48시간 보존용 로컬 아카이브를 남긴 뒤 작업용 백업을 정리합니다.
- 강제확정 후 서버 제출본과 다른 로컬백업이 있으면 학생 화면에 브라우저 데이터를 지우지 말라는 안내가 표시됩니다.
