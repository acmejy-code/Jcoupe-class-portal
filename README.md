# JCOUP 학생 포털 v1.6.8 — 반별 수행평가 완전 분리

## 핵심 변경
- 학생이 선택한 반에 포함된 WAITING/OPEN 수행평가만 응시 목록에 표시합니다.
- 다른 반의 오래된 평가가 OPEN으로 남아 있어도 현재 반의 평가 목록·입장·응시에 섞이지 않습니다.
- 반을 바꾸면 이전 반 평가 선택을 즉시 해제하고 현재 반 평가 목록을 다시 그립니다.
- 서버 저장·최종제출·복구 백업 기능은 v1.6.7 그대로 유지합니다.
- Firestore Rules 변경 없음. 실제 응시 인증은 기존 Rules가 학생의 실제 반과 targetClasses를 다시 검증합니다.
