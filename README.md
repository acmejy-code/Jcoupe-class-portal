# 독-토-글 수업 종합 포털 v1.4.1

## 이번 개선
- 관리자 v2.4.1의 `학생 화면 테스트`를 **별도 새 창**으로 받을 수 있도록 개선
- 팝업 창이 관리자 창에 준비 완료 신호를 보내고, 관리자 창에서 테스트 평가/학생 데이터를 전달
- 테스트 모드 상단에 `관리자 테스트 모드 · 서버 저장 안 함` 배너 표시
- `테스트 창 닫기` 버튼 추가
- 테스트 모드에서 입력한 답안은 Firestore뿐 아니라 일반 학생용 localStorage 백업에도 남기지 않도록 분리
- 실제 학생 응시의 학번+이름+공통 응시코드, 자동저장, 재접속 복원, 최종 제출 기능은 그대로 유지
