# 독-토-글 수업 종합 포털 v1.2.1

## 변경 사항
- `수업 진도` 탭에서만 A/B/C/E반 선택 UI를 표시합니다.
- `수업 자료실` 탭에서는 반 선택 UI를 표시하지 않습니다.
- 자료실은 반 구분 없이 모든 공통 공개 자료를 즉시 표시합니다.
- 자료 분류 필터, 검색, 미리 보기, 다운로드 기능은 그대로 유지합니다.
- 기존 수업 진도와 Firebase/Firestore 연동 구조는 변경하지 않았습니다.

## 배포
기존 `Jcoupe-class-portal` 저장소의 파일을 이 배포본으로 전체 덮어쓴 뒤 Commit → Push origin → GitHub Actions 완료 확인 → Ctrl+F5 순서로 확인합니다.
