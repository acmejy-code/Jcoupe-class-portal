# JCOUP 학생 수업 종합 포털 v1.6.0

기준: v1.5.1 수행평가 집중 모드 + 안내문 줄바꿈 유지

## 주요 개선

### 수행평가 시간
- 교사가 평가를 시작한 공통 시각 기준으로 남은 시간 표시
- 10분 / 5분 / 1분 구간 안내
- 시간 종료 시 자동 제출
- 전체 연장시간과 개인 추가시간을 실시간 반영

### 자동 저장·복구
- 답안 입력 후 약 1.2초 뒤 자동 저장
- 12초 간격 안전 저장
- 로컬 백업 유지
- 재접속 시 서버 답안과 기기 백업을 병합하여 복원
- 오프라인 상태에서는 기기에 임시 보관하고 재연결 후 저장/제출 재시도

### 응시 전 기기 점검
- 인터넷 연결
- 로컬 자동 저장
- 화면 이탈 감지 가능 여부 표시

### 감독 이벤트
- 탭 전환/창 포커스 이탈
- 복사
- 붙여넣기
- 우클릭
- 오프라인/재연결
- 학생에게 별도 방해 팝업을 띄우지 않고 관리자 감독 화면에 기록

### 학번
- 4자리·5자리 모두 입력 가능
- 실제 명단이 5자리인 경우에도 대표적인 4자리 형식을 자동으로 변환하여 인증 시도

### 기존 기능 유지
- 수행평가 입장 후 상단 메뉴 숨김(집중 모드)
- 응시 안내 줄바꿈 유지
- 관리자 테스트 모드 응시코드 자동 채움
- 실제 학생은 응시코드를 직접 입력
- 공지 / 수업 자료실 / 진도 메뉴 유지

1. `Jcoupe-class-portal` 저장소의 기존 파일을 학생 폴더 내용으로 전체 교체
2. Commit

5. 학생 단말에서 새로고침 또는 재접속
