# JCOUP 학생 포털 v1.6.4 — 강제 자동 제출 동기화 안정화

기준: v1.6.3의 학사일정·수업진도 달력과 v1.6.2의 대기실 재입장/기기 인계 기능을 모두 유지합니다.

## v1.6.4 추가 개선
- 관리자에서 시험시간 종료로 강제 제출된 상태를 실시간으로 수신하면 서버에 확정된 답안으로 화면을 즉시 동기화
- 강제 제출 직전에 기기에 남아 있던 미저장 임시 답안이 화면에 제출 답안처럼 남지 않도록 정리
- 시간 종료 자동 제출과 교사 평가 종료에 의한 자동 제출을 학생 화면에서 구분하여 안내
- 학생이 직접 제출한 경우 `MANUAL`, 시간 종료 자동 제출은 `TIME_EXPIRED` 제출 사유를 기록
- 강제 제출 후 로컬 임시 백업과 재시도 예약을 정리하여 제출 완료 뒤 중복 저장을 방지

## 주의
시험 종료 자동 확정은 서버에 **마지막으로 저장된 답안**을 기준으로 합니다. 따라서 응시 중 자동 저장 상태가 정상인지 학생 화면에서 확인하는 것이 중요합니다.
